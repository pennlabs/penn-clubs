[Action Needed] Committee Questions Bug in Duplicated Penn Clubs Applications

Dear Club leaders,

You are receiving this email because you are hosting applications on Penn Clubs. We have discovered a bug that only affects applications that use committees; if your application has no committees or no committee-specific questions, no action is needed on your part.

If your Fall 2026 application uses committees, it is likely affected and we request that you please take a few minutes to check your applications as soon as possible.

As you may know, we allow questions to be targeted towards specific committees. When applications are duplicated from previous applications, either as part of an automatic Wharton Council process or manually using the Duplicate button, these committee-specific questions are duplicated for Fall 2026, but are no longer associated with their assigned committees.

As a result, applicants may not be seeing the questions you intended for them.

To check whether your application is affected, we recommend the following steps.

  1. Please use the Preview feature on your applications by previewing different committees to determine if this bug affects you.
  2. If you intended for there to be committee-specific questions and you do not see them, use the Edit Questions utility to relink the questions to their committees and make sure to Save all changes.
  3. Use Preview again to ensure that your application looks correct.

The visual guide below shows where to find each step.

Please do not hesitate to reach out immediately if you have any questions or notice any additional bugs. We apologize for any inconvenience caused.

Best regards,

Penn Clubs
